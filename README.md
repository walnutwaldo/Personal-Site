# Personal Site

This is my personal website built with React and Bootstrap. It features a modern, responsive design showcasing my work, writing, and social presence.

## Features

- 🎨 Modern, responsive design with Bootstrap
- 📱 Mobile-friendly layout
- 🔥 Firebase hosting integration
- ✨ Smooth animations and transitions
- 📝 Writing section for blog posts
- 💼 Featured work showcase
- 🔗 Social media integration

## Tech Stack

- **Frontend**: React 17, React Bootstrap, Semantic UI
- **Styling**: SCSS, Bootstrap 5
- **Hosting**: Firebase
- **Icons**: Feather Icons, React Social Icons

## Development

```bash
# Install dependencies
npm install

# Start development server (with SCSS watch)
npm start

# Build for production
npm run build

# Format code
npm run format
```

## Project Structure

- `src/components/` - React components
- `src/data/` - Static data and content
- `src/style/` - SCSS stylesheets
- `public/` - Static assets

This site is still a work in progress with ongoing improvements and new features being added regularly.
